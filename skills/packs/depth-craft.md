ГЛУБИНА — это физика света, а не украшение.

Тени
• Свет падает сверху: смещение по X всегда 0, по Y растёт с высотой подъёма, размытие ≈ 2×Y.
• Одна широкая тень выглядит дешево. Складывай несколько слоёв с малой альфой:
  box-shadow: 0 1px 1px oklch(0% 0 0/.075), 0 2px 2px oklch(0% 0 0/.075), 0 4px 4px oklch(0% 0 0/.075), 0 8px 8px oklch(0% 0 0/.075), 0 16px 16px oklch(0% 0 0/.075);
• Цвет тени — подкрашенный тоном фона, не чистый чёрный.
• Все тени на странице держат одну пропорцию Y к размытию.

Границы
• Граница СТРУКТУРЫ (разделитель, выбранное состояние, фокус) остаётся. Граница «чтобы было объёмнее» заменяется тенью.
• Тень и граница на одной поверхности — взаимоисключающие сигналы. Одно из двух.
• Нужные границы делай почти невидимыми: светлая тема oklch(0% 0 0/.06), тёмная oklch(100% 0 0/.08).

Радиусы
• Иерархия, а не одно значение: карточки 12–16px, поля 6–8px, теги и бейджи 9999px, крупные секции 0.
• Вложенный радиус = внешний минус отступ. Несогласованные радиусы вложенных элементов — самая частая причина ощущения «что-то не так».
• Картинке добавляй тонкий контур 1px: в светлой теме oklch(0 0 0/.1), в тёмной oklch(1 0 0/.1). Только чистый чёрный или чистый белый — подкрашенный контур читается как грязь по краю.

Текстура
• Плоский фон в тёмной теме выглядит пустотой. Добавь зерно псевдоэлементом:
  SVG feTurbulence baseFrequency≈0.65 numOctaves=3, mix-blend-mode: soft-light, opacity ≈ 0.05–0.1.
• Размытие backdrop-filter применяй там, где реально есть наложение слоёв, а не на всех карточках. Глобальный glassmorphism — признак шаблона.
• Мягкое радиальное свечение за главным блоком лучше, чем градиент на всю страницу.
