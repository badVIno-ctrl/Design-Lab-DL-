НАВИГАЦИЯ И КАРКАС
• Якоря скроллят плавно (scroll-behavior:smooth); sticky-шапка компенсируется padding-top, а у страницы scroll-padding-top — фокус и контент не прячутся под ней.
• Текущий раздел подсвечен в меню. URL отражает состояние, которым делятся ссылкой.
• z-index по шкале (10/20/30/50), никаких 9999.
• Асинхронный контент (картинки, бейджи, счётчики) резервирует место заранее (aspect-ratio, стабильный слот) — вёрстка не дёргается при догрузке.
• Вместо 100vh на мобильных — 100dvh. Длинные ссылки и идентификаторы: overflow-wrap:anywhere и min-width:0 у flex-детей, чтобы не было горизонтальной прокрутки.

КАСАНИЯ И УКАЗАТЕЛЬ
• Цель касания ≥44px; на вебе минимум 24×24 CSS px; между соседними целями ≥8px.
• У кнопок touch-action:manipulation. Свайпы не перекрывают системные жесты.
• Кольцо фокуса не удаляется без замены: min 2px, контраст к фону 3:1.

ДОСТУПНОСТЬ (минимум WCAG 2.2 AA)
• Иконочная кнопка имеет aria-label. Ошибка стоит у своего поля (aria-describedby) и объявляется role="alert", а не только красной рамкой.
• Всё доступно с клавиатуры, порядок табов совпадает с визуальным; есть skip-link к содержимому.
• Перетаскивание дублируется кнопками (вверх/вниз) — drag не единственный способ.
• Пароль вставляется из буфера; вход не строится на «когнитивном тесте» без альтернативы.

КАРУСЕЛИ, ВИДЕО, ТИКЕРЫ
• У автоленты есть prev/next и пауза; она встаёт на hover/focus и при prefers-reduced-motion.
• Видео: субтитры, видимая пауза, никакого автоплея со звуком; вне экрана — стоп.
• «Live»-счётчики, наличие мест, рейтинги — только подтверждённые и датированные, иначе пиши качественно.

КОНВЕРСИЯ И СТРУКТУРА
• Один первичный CTA на экран; социальное доказательство стоит ПЕРЕД CTA, не после.
• Лид-форма просит только нужное для выдачи результата; у многошагового процесса есть индикатор шага.
• Тарифы: выделен один план под целевую аудиторию, FAQ закрывает возражения, годовая экономия показана честно.
• Сравнение с конкурентами фактическое, своя колонка подсвечена.
• Пустое состояние ведёт к действию («Создай первый…»); «ничего не найдено» предлагает альтернативу.
• Тосты исчезают сами через 3–5 секунд; успешное действие всегда подтверждено.

ПРОИЗВОДИТЕЛЬНОСТЬ ВЁРСТКИ
• Картинки: размер под место и srcset; ниже сгиба — loading="lazy".
• Шрифты: font-display:swap и близкий по метрикам фолбэк — без сдвига вёрстки при догрузке.
• Сторонние скрипты async/defer. Анимируются transform/opacity/фильтр, не width/top/left.
