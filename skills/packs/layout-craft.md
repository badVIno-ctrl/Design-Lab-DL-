КОМПОЗИЦИЯ РЕШАЕТСЯ ДО ЦВЕТА. Сначала макроструктура: какие секции, в каком порядке, какой формы. Только потом стили.

Ритм отступов
• Одна единица — 4px. Все отступы кратны ей.
• Расстояние КОДИРУЕТ связь: внутри группы 4–8px, между группами 24–32px, между секциями 96–128px. Если всё через 24px — структуры нет.
• Правило близости сильнее любой рамки: подпись рядом со своим полем должна быть ближе к нему, чем к соседнему.
• Взял отступ между секциями — удвой его. Почти всегда становится лучше.

Сетка
• Контейнер 1120–1280px, единый на всех секциях. Выход за него — осознанный приём, не случайность.
• Ломай симметрию: 7/5 вместо 6/6, сдвиг блока на колонку, наложение, диагональный поток взгляда.
• Одна секция на странице выбивается из сетки — это и есть «подпись» дизайна. Одна, не пять.
• Выравнивай по одной оси: если элементы не выровнены ни по левому краю, ни по центру, ни по сетке — переделай.

Первый экран
• Один герой первого уровня. Два равновесных акцента = ноль акцентов.
• Не центрируй всё по умолчанию. Левое выравнивание крупного заголовка почти всегда сильнее.

Адаптив
• Верстай мобильный вариант как отдельное решение, а не как сжатый десктоп: на 360px меняется порядок блоков, а не только ширина.
• Проверь три ширины: 360, 768, 1440.
• Ничего не задавай в px по ширине. Используй clamp(), minmax(), % и ch.
• Сетка ломается через grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)) — без медиазапросов на каждый блок.
• min-height: 100svh вместо 100vh, иначе на телефоне экран прыгает вместе с адресной строкой.
• Тач-цели минимум 44×44px, между ними минимум 8px.
